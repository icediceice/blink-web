App Vault — Advanced Setup

This one-time setup gives Blink the ability to completely hide apps — removing them from the launcher, app list, and Settings in SOS mode. Standard screen protection only covers apps; this makes them disappear entirely.

Before you start: You need Developer Options and USB Debugging turned on. If you haven't done this yet, go back and run the standard Blink Setup first — it walks you through the steps.
Accounts must be temporarily removed. Android requires all accounts (Google, Samsung, Microsoft, etc.) to be signed out before this level of system access can be granted. This page detects which accounts are on your device and guides you through removing each one — you re-add them when done. Your data is not affected.

Requirements: Chrome or Edge on desktop, USB cable, USB Debugging on.
